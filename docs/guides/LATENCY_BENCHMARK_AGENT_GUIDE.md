# Latency benchmark documentation

The implemented commands and operating instructions are in the
[latency benchmark runbook](latency-benchmark.md).

The earlier mission, implementation tickets, proposed interfaces, and report
templates are preserved as a
[historical specification](../history/implementation-plans/guides-LATENCY_BENCHMARK_AGENT_GUIDE.md).
They are design context, not a second current command reference or a statement
that every proposed feature was implemented.

Use the runbook for current flags, data/account boundaries, artifact locations,
measurement caveats, and tests. For underlying component behavior, start with
[system architecture](../architecture/design.md).
